# English শিখি — GitHub Pages site

A responsive, static website for the English শিখি Android learning app. It uses plain HTML, CSS, and vanilla JavaScript; there is no build step or external runtime dependency.

## Pages

- `index.html` — app overview and features
- `privacy-policy.html` — privacy policy
- `terms.html` — terms and conditions
- `data-deletion.html` — local data and deletion instructions

## Publish on GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)` folder, then save. GitHub Pages will publish the site over HTTPS once deployment finishes.

Replace `your-email@example.com` in the HTML pages with the app's public contact email before publishing. The privacy policy's last-updated date is shown on the policy page.
